# Dataset Card — UMiKT-GAT

## Summary

This dataset card documents all data sources used in the UMiKT-GAT research codebase.
**Read this before interpreting any experimental results.**

---

## Data Layers

### Layer 1 — Public Knowledge Tracing Dataset

| Field | Value |
|---|---|
| **Name** | ASSISTments 2009-2010 Skill Builder (if successfully downloaded) |
| **Source** | https://sites.google.com/site/assistmentsdata/home/assistment-2009-2010-data |
| **License** | Freely available for research purposes. See ASSISTments website for full terms. |
| **Download script** | `data/layer1_public_kt/download_assistments.py` |
| **Used for** | Mastery prediction baseline (Phase 3), BKT/DKT baseline comparisons |

> [!WARNING]
> If `data/layer1_public_kt/layer1_metadata.json` shows `"is_real_data": false`, the
> real ASSISTments dataset could not be downloaded and a **synthetic fallback** was used.
> In that case, ALL Phase 3 and baseline metrics are from synthetic data and must not
> be presented as ASSISTments benchmark results.

**Preprocessing applied:**
- Filtered rows where correctness ∉ {0, 1}
- Capped response time at 600 seconds; log-normalized
- Normalized attempt count to [0,1] by dividing by 5
- Split 70/15/15 train/val/test by learner ID (no learner appears in multiple splits)

### Layer 2a — Synthetic Programming Fundamentals Dataset

| Field | Value |
|---|---|
| **Name** | UMiKT-GAT Synthetic Learner Trajectories |
| **Generator** | `data/layer2_synthetic/generate_synthetic.py` |
| **Split sizes** | Train: 200 learners × 30 interactions = 6,000 rows; Val: 1,500; Test: 1,500 |
| **Random seeds** | Train: 42, Val: 123, Test: 999 |
| **License** | N/A — generated data |

> [!CAUTION]
> **THIS IS SYNTHETIC DATA.** All files include the string "(synthetic)" in their headers.
> Never present results from this layer as evidence of real student performance.

**What the simulation generates:**
- Ground-truth mastery: logistic growth model with per-learner rates
- Misconception state: Markov chain over 7-class taxonomy
- Forgetting: exponential decay with per-concept rate
- Observed correctness: noisy Bernoulli from (mastery − misconception penalty)
- Response time: log-normal conditioned on concept difficulty

**What this is used for:**
- Training and evaluating all UMiKT-GAT ablation variants (Phases 3–8)
- Validating that the model recovers known latent states from generated trajectories
- Running the full multi-agent demo session (Phase 10)

**What this CANNOT support:**
- Claims about real student misconception patterns
- Claims about real forgetting rates or retention dynamics
- Generalizable curriculum effectiveness claims

### Layer 2b — Handwritten Q&A Evaluation Set

| Field | Value |
|---|---|
| **Name** | UMiKT-GAT Handwritten Programming Q&A Pairs |
| **File** | `data/layer2_handwritten/qa_pairs.json` |
| **Size** | 50 question-answer pairs |
| **Domain** | Programming Fundamentals / Data Structures |
| **Misconception labels** | Hand-labeled against the taxonomy in `misconception_taxonomy.md` |

**Used for:**
- Offline evaluation of the MockLLMProvider extraction quality
- Spot-checking the misconception taxonomy coverage
- NOT used for model training

**Limitations:**
1. 50 items is too small for statistically significant LLM evaluation
2. Labels are hand-authored by a single annotator — no inter-rater reliability
3. Coverage is uneven across concepts (more recursion/loop items than variables)

## Limitations and Threats to Validity

1. **Synthetic-data reliance**: The primary evaluation data is synthetic. The simulation
   makes modeling assumptions (logistic growth, Markov misconceptions, exponential forgetting)
   that may not reflect real student learning dynamics.

2. **Label quality**: Misconception labels in the synthetic data are sampled from a
   prior distribution. The handwritten labels are single-annotator. Neither represents
   validated ground truth.

3. **Dataset size**: Even if the real ASSISTments dataset is used, it does not contain
   misconception labels, open-ended responses, or the prerequisite graph used by UMiKT-GAT.
   This mismatch means the full model cannot be evaluated on real data without additional
   data collection.

4. **Domain scope**: The misconception taxonomy and concept graph cover only 7 programming
   concepts. Results do not generalize to other learning domains.

5. **Temporal validity**: No real longitudinal data is available to validate the retention/
   forgetting modeling. The exponential decay parameters are fitted to synthetic data
   generated by the same model, which creates a circularity that inflates retention metrics.

6. **No user study**: RQ5 (curriculum decision quality → learning efficiency) cannot be
   answered without a controlled prospective experiment with real students. The demo session
   shows the pipeline runs, not that it produces better learning outcomes.
